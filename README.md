# Yala City Fan Trip

เว็บแอป (PWA) สำหรับผู้จัดการทริป บันทึกรายชื่อคนไปดูบอลยะลาซิตี้ เช็คยอด และเช็คอินวันเดินทาง
ติดตั้งลงหน้าจอมือถือได้เหมือนแอปจริง พร้อมไอคอนโลโก้ — ข้อมูลเก็บใน **Google Sheet** ของคุณเอง

```
มือถือ (GitHub Pages: index.html + app.js)  ──►  Google Apps Script (Code.gs)  ──►  Google Sheet
```

## ติดตั้ง (ทำครั้งเดียว ประมาณ 10 นาที)

### 1) สร้างหลังบ้านบน Google
1. เข้า [sheets.new](https://sheets.new) สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น `Yala City Fan Trip`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจากไฟล์ `apps-script/Code.gs`
4. บรรทัดบนสุด แก้ `const INITIAL_PASSWORD = '';` ใส่รหัสผ่านที่ผู้จัดการทั้ง 2 คนจะใช้ เช่น `'yala2026'`
5. เลือกฟังก์ชัน **setup** ที่แถบด้านบน กด **Run** → กดอนุญาตสิทธิ์ (Google อาจเตือน "ยังไม่ได้ยืนยัน" ให้กด Advanced → Go to … เพราะเป็นสคริปต์ของคุณเอง)
   - จะได้ชีต `Trips` และ `People` พร้อมหัวตารางอัตโนมัติ
6. **ลบรหัสผ่านออกจาก `INITIAL_PASSWORD` กลับเป็น `''` แล้วกดบันทึก** (รหัสถูกเก็บแบบแฮชไว้ในระบบแล้ว)
7. กด **Deploy (ทำให้ใช้งานได้) → New deployment → เลือกประเภท Web app**
   - Execute as (เรียกใช้ในฐานะ): **Me (ฉัน)**
   - Who has access (ผู้มีสิทธิ์เข้าถึง): **Anyone (ทุกคน)**
   - กด Deploy แล้วคัดลอก **Web app URL** (ขึ้นต้น `https://script.google.com/macros/s/…/exec`)

> "Anyone" หมายถึงใครก็เรียก URL ได้ แต่ทุกคำสั่งต้องใช้รหัสผ่านของคุณ ไม่มีรหัส = ไม่ได้ข้อมูลใด ๆ
> ใส่รหัสผิด 5 ครั้งระบบล็อก 5 นาที

### 2) ใส่ URL ในแอป
เปิดไฟล์ `config.js` แล้วใส่ URL:
```js
window.APP_CONFIG = { API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec' };
```

### 3) ขึ้น GitHub + เปิด GitHub Pages
1. สร้าง repository ใหม่บน GitHub (แนะนำ **Private** ถ้าใช้ GitHub Pro/Team; แบบ Public ก็ได้ เพราะในโค้ดไม่มีรหัสผ่านหรือข้อมูลบุคคล มีแค่ URL หลังบ้าน)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (หรือ `git push`)
3. ไปที่ **Settings → Pages → Build and deployment**: Source = **Deploy from a branch**, Branch = `main`, โฟลเดอร์ `/ (root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

### 4) ติดตั้งเป็นแอปบนมือถือ
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป** (หรือกด "ติดตั้งแอปลงหน้าจอ" ในหน้าตั้งค่าของแอป)

จะได้ไอคอนโลโก้ยะลาซิตี้บนหน้าจอ เปิดแล้วเต็มจอไม่มีแถบเบราว์เซอร์

## การใช้งานกับผู้จัดการ 2 คน
ส่งลิงก์แอปและรหัสผ่านให้อีกคน เขาเปิดแล้วกรอกรหัสได้เลย ข้อมูลเป็นชุดเดียวกัน (แอปซิงก์ทุก 20 วินาที และเมื่อกลับมาเปิดแอป)

## ระบบตั๋ว
- ตอนสร้าง/แก้ไขรอบ เลือกได้ว่า **ไม่ใช้ตั๋ว (เข้าฟรี)** หรือ **ต้องมีตั๋ว** (ใส่ราคา/วันเปิดขายได้)
- รอบที่ต้องมีตั๋ว: แต่ละคนมีปุ่ม **ได้ตั๋วแล้ว / ยังไม่มีตั๋ว** กดสลับได้ มีช่องติ๊กตอนเพิ่มรายชื่อ ตัวกรองตั๋ว สรุปยอด และคอลัมน์ตั๋วใน CSV
- **ค่าตั๋ว:** ใส่ "ราคาตั๋วต่อใบ" ในฟอร์มรอบ แต่ละคนมีปุ่ม **จ่ายแล้ว / ยังไม่จ่าย** (บันทึกเวลาที่จ่ายด้วย) แอปสรุปยอดเก็บแล้ว/ค้างจ่ายให้ ถ้าไม่ใส่ราคาจะนับเป็นจำนวนคนแทน
- **ตัวกรอง 2 แถว:** แถว "ตั๋ว" (ทั้งหมด / ยังไม่มีตั๋ว / ได้ตั๋วแล้ว) และแถว "เงิน" (ทั้งหมด / ยังไม่จ่าย / จ่ายแล้ว / จ่ายแล้ว-ไม่มีตั๋ว / มีตั๋ว-ไม่จ่าย) พร้อมตัวเลขจำนวนคน ตั๋ว + ยังไม่จ่าย/จ่ายแล้ว ใช้ร่วมกันได้
- **2 กลุ่มที่ต้องตามงาน (ปุ่มขอบแดงในแถวเงิน):** **จ่ายแล้ว-ไม่มีตั๋ว** (เงินเก็บแล้วรอซื้อตั๋ว) และ **มีตั๋ว-ไม่จ่าย** (ต้องตามเก็บเงิน) กดแล้วแถวตั๋วจะล้างและจางลงเอง กดซ้ำเพื่อยกเลิก
- CSV มีคอลัมน์ ตั๋ว / ค่าตั๋ว / เวลาที่จ่าย
- รอบที่ไม่ใช้ตั๋ว: ไม่แสดงส่วนตั๋วและค่าตั๋วเลย

## อัปเกรดจากเวอร์ชันก่อนหน้า (ระบบตั๋ว / ค่าตั๋ว)
ข้อมูลเดิมไม่หาย รอบเดิมจะเป็น "เข้าฟรี" และทุกคนเป็น "ยังไม่มีตั๋ว/ยังไม่จ่าย" จนกว่าจะแก้
1. **Apps Script:** เปิดโปรเจกต์เดิม แทนที่โค้ดด้วย `apps-script/Code.gs` ใหม่ (**ตรวจว่า `INITIAL_PASSWORD` ยังเป็น `''`**) แล้วบันทึก
2. **Deploy เวอร์ชันใหม่:** Deploy → Manage deployments → ✏️ → Version: **New version** → Deploy (URL เดิมใช้ต่อได้)
3. **GitHub:** อัปโหลดทับเฉพาะไฟล์ `app.js`, `index.html`, `sw.js`, `README.md` (**ห้ามอัปโหลดทับ `config.js`** เพราะมี URL ของคุณอยู่)
4. ระบบจะเพิ่มหัวคอลัมน์ `ticketMode`, `ticketInfo`, `ticketPrice` (แท็บ Trips) และ `ticket`, `paid`, `paidAt` (แท็บ People) ในชีตให้เองตอนบันทึกครั้งแรก
5. เปิดแอปใหม่ 2 ครั้งเพื่อให้ได้เวอร์ชันล่าสุด

## ข้อมูลอยู่ที่ไหน / สำรอง
- ทุกอย่างอยู่ใน Google Sheet ของคุณ ดู/แก้/ดาวน์โหลดได้ตรงนั้น (ไฟล์ → ดาวน์โหลด → Excel)
- ข้อมูลส่วนบุคคลอยู่ใน Sheet ของคุณเท่านั้น ไม่ได้อยู่ใน GitHub **อย่าแชร์ Sheet ให้คนอื่นโดยไม่จำเป็น**
- อย่าเปลี่ยนลำดับ/ชื่อหัวคอลัมน์ในชีต `Trips` และ `People`

## แก้โค้ดหลังบ้านภายหลัง
แก้ `Code.gs` แล้ว **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
(URL เดิมยังใช้ได้ ถ้าสร้าง deployment ใหม่ URL จะเปลี่ยน ต้องแก้ `config.js`)

## เมื่ออัปเดตหน้าแอป
หลังพุชโค้ดใหม่ ปิดแล้วเปิดแอปสองครั้งเพื่อให้ได้เวอร์ชันล่าสุด (ถ้าแก้ไฟล์ที่ cache ไว้ ให้เพิ่มเลข `VERSION` ใน `sw.js`)

## ข้อจำกัดของ MVP
- ต้องมีอินเทอร์เน็ตตอนบันทึก (เปิดหน้าแอปได้แม้สัญญาณช้า แต่ยังไม่มีคิวบันทึกออฟไลน์)
- Google Apps Script ตอบสนองราว 1–2 วินาทีต่อครั้ง การเพิ่มรายชื่อจึงแสดงในรายการทันทีแล้วบันทึกเบื้องหลัง
- โควตา Apps Script ฟรีเพียงพอสำหรับผู้ใช้ 1–2 คน

## โครงสร้างไฟล์
```
index.html, app.js, config.js   หน้าแอป
manifest.webmanifest, sw.js     PWA (ติดตั้งได้ / เปิดเร็ว)
icons/, assets/                 ไอคอนแอปและโลโก้
apps-script/Code.gs             หลังบ้าน (วางใน Apps Script)
apps-script/appsscript.json     (ไม่บังคับ) ตั้งเขตเวลา Asia/Bangkok
```
